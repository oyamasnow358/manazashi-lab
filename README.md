# まなざし ラボ（MieeL）

先生用：iPad の前面カメラで顔と目の動きを読み取り、見る・集中のようすを記録して「前の自分と比べる」ツール。**診断はしません。**

- ⭐ しゅうちゅう チャレンジ … Go/No-Go 型の持続的注意課題（見のがし・押しまちがい・反応時間とばらつき）＋頭の動き・よそ見
- 👀 どっちを みる？ … 左右に2つ並べて、どちらを長く・先に見るか（選好注視・左右入れかえ）
- 🖼️ きょうざいを みる … 教材の写真のどこを見たか（ヒートマップ・3×3・注視）
- 🎯 見る ばしょ あわせ（9/5/3点）… リッジ回帰でキャリブレーション、毎回ずれを検証して記録
- 📊 レポート … 指標・時間の流れ・これまでの平均との比較・印刷（A4）・CSV
- 映像は保存・送信しない。記録は端末の IndexedDB のみ（バックアップ JSON あり）

## つくりかた
```
python _src/build.py        # _src/ → index.html, sw.js
python -m http.server 8822  # http://localhost:8822/
```
MieeL 本体（my-portfolio）の /page/manazashi から iframe で表示（next.config.mjs で github.io にだけカメラを委任）。
